# Scout branding assets

This folder contains the static branding files served directly by Vite.

- `logo.svg` — the mark displayed in the application header.
- `favicon.svg` — the icon displayed in the browser tab.

Replace these files with your final artwork while keeping the same filenames, or update the references in `src/app-shell/AppShellHeader.tsx` and `index.html`.

Recommended: use an SVG for crisp scaling. If you use PNG instead, update the file references and MIME/type accordingly.
